Repository and privacy

  • The repository is public. Raw household inputs are kept in an ignored local folder and are not included in the Pages artifact.
  • Jekyll exclusions restrict the Pages artifact only. They do not hide excluded files or existing Git history from GitHub code browsing, clones, forks, or cached copies.
  • The pre-rounding history has not been scrubbed. This checkout begins at a grafted commit, so older objects could not be inspected or safely rewritten here. See PRIVACY_REMEDIATION.md; do not interpret Pages containment as a history purge.
  • The privacy gate checks every root dashboard page, published asset, data file, and printable brief against the internal input values before publishing.
