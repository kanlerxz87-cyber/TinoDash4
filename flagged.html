Repository and privacy

  • Containment is partial: the current Pages configuration excludes alternate generated site trees and source folders, but the GitHub repository remains public and those tracked files and historical commits can still be fetched directly.
  • Rounded projections are derived from household assumptions and may still be linkable to public records; rounding is not a guarantee of anonymity.
  • The earlier pre-rounding history was not scrubbed in this change. The current checkout does not provide the earlier objects needed to inspect or safely rewrite that history.
  • Default strict checking requires the ignored private inventory and fails closed when it is absent; --public-only explicitly skips exact comparison for clean CI. Neither result certifies that rounded projections are anonymous.

Privacy: figures use placeholders and rounded, derived outputs, which are not guaranteed anonymous; public Git history has not been purged. Not legal or tax advice.
