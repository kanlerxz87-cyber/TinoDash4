# Inherited-home decision dashboard (published folder)

Published at `https://kanlerxz87-cyber.github.io/TinoDash4/dashboard/`. Start at `index.html`.

Generated by `tools/dashboard_model.py` (model), then `tools/dashboard_build.py` (pages), and checked by `tools/dashboard_check.py` (gate). Inputs: the owner's property figures rounded to $10 are in `private/dashboard_inputs.json` (gitignored; never published; the model and build read this path). The source register (`data/sources.json`) and the historical return record (`data/returns_1928_2025.csv`) are in `data/`.

Privacy: no addresses, ZIP codes or account numbers. Dollar figures are rounded to $10 except statutory amounts, which are checked against the register. Not legal, tax or investment advice.
