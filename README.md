# Inherited-home decision dashboard

A privacy-first GitHub Pages site that compares paths for an inherited home (Property A, Santa Clara County, single-family, expected transfer around 2040 to 2050) against an already-owned three-unit building (Property B, San Francisco County).

**Start here:** `index.html` (served at the repository's GitHub Pages address). It opens with the summary and "What would change the answer".

## What is in the repository

| Path | What it is |
|---|---|
| `index.html`, `pages/`, `assets/` | The published site, generated by `tools/build_site.py` from the data files below. |
| `DECISION_RULES.md` | The choice rules, written 25 November 2026 before any model output. The model applies them; it does not set them. |
| `data/inputs.json` | Owner-supplied property figures, rounded to the nearest $10. No income, account or debt figures. |
| `data/sources.json` | The source register (S01 to S23) with the status of each source. |
| `data/returns_1928_2025.csv` | Annual S&P 500 total return and 3-month T-bill return, 1928-2025 (academic dataset; see Flagged F-13). |
| `data/model_outputs.json` | Results from `tools/model.py`. Rounded; no inputs beyond those above. |
| `tools/model.py` | The decision model: eight paths, Monte Carlo, crash replays, rules, sensitivity, what-if table and projections. |
| `tools/build_site.py` | Builds every page from the data files. |
| `tools/check_site.py` | Publication gate (see below). |
| `COORDINATION.md` | The multi-session board: tasks, claims, log and verification. |

## Rebuild and check

```
python3 tools/model.py                   # about 30 seconds; deterministic (seeded)
python3 tools/build_site.py
python3 tools/check_site.py --structural # structure, rounding, links, source register, row markers
python3 tools/check_site.py              # full gate, local only (privacy scan; needs private/raw_inputs.json)
```

## Privacy

- No street address, ZIP code, parcel number or account number is in the repository. Properties are "Property A" and "Property B" with the county only. People are placeholders such as [HEIR].
- Dollar figures on the site are rounded to $10; statutory amounts are printed exactly and checked against the register.
- `private/` is gitignored. It holds the internal scan list (`private/raw_inputs.json`) and copies of earlier site files removed from the published tree. Nothing in it is published.
- The privacy scan runs locally, because the internal list is never committed. CI runs the structural checks only.
- Git history still contains material removed from the tree; rewriting history needs owner approval (Suggestion SG-10).
